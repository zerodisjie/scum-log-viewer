# SCUM 服务器日志查看器

[![Release](https://img.shields.io/github/v/release/zerodisjie/scum-log-viewer)](https://github.com/zerodisjie/scum-log-viewer/releases/latest)
[![Python](https://img.shields.io/badge/python-3.9%2B-blue)](https://www.python.org/)

版本 **v0.1.0**（本地运行，零第三方依赖，Python 3.9+）

本地跑的 SCUM 服务器日志阅读工具。双击启动，浏览器里看，不用装任何第三方库。

```
双击  启动日志查看器.bat       本机看
双击  start-server.bat         服务器上开给局域网/远程看
```

打包好的免安装版：[Releases](https://github.com/zerodisjie/scum-log-viewer/releases/latest) → `SCUMLogViewer-0.1.0.zip`，解压双击 `start.bat` 就能看。

## 核心：日志自动合并

SCUM 的日志按 6 小时滚动切分，一天 4 个文件，一个月下来一个类型就上百个。这个工具把日志拼成连续时间线——**不用管文件，只看类型**：

```
全部日志        →  目录里所有类型的日志混排成一条总时间线
  登录登出      →  这一类散落在各个滚动文件里的记录合并成一条
  击杀          →  同上，按时间先后排好
```

- **侧栏只有类型按钮**，不再列文件、不显示路径：点哪个类型就看哪一类，条数和日期范围直接标在按钮上
- **「全部日志」置顶**：所有类型按时间混排成一条总时间线，还原服务器这段时间到底发生了什么
- 时间列直接带日期（`10-14 12:16:17`），跨天一眼能看出来
- 只为 `Game version` 占位的空日志组会排到末尾并置灰，标「空」

## 表格化显示

每类日志按内容拆成表格，列随类型变：

| 类型 | 表头 |
|---|---|
| 登录登出 | 时间 · 动作 · 玩家昵称 · 玩家ID · IP 地址 · 位置（X, Y, Z） |
| 击杀 | 时间 · 受害者 · 受害者ID · 击杀者 · 击杀者ID · 武器 · 距离 |
| 聊天 | 时间 · 玩家昵称 · 玩家ID · 频道 · 内容 |
| 管理员指令 | 时间 · 玩家昵称 · 玩家ID · 指令 |
| 载具销毁 | 时间 · 事件 · 载具 · 载具ID · 车主 · 位置 |
| 声望变动 | 时间 · 玩家昵称 · 玩家ID · 声望 · 统计周期 · 累计 · 明细项 |
| 箱子归属 | 时间 · 箱子ID · 归属玩家 · 玩家ID · 位置 |
| 违规检测 | 时间 · 事件 · 违规动作 · 描述 · 位置 |
| 玩法记录 | 时间 · 对象 · 状态 · 发生于 · 位置 |
| 全部日志 | 时间 · 类型 · 事件 · 玩家 · 内容 |

- 拆不出字段的行（标题行、异常格式）原文横跨整行显示，不会被吞
- 点任意一行，右侧把该行所有字段逐条列出来，SteamID / IP 可一键复制
- 「事件」列来自行首的 `[VehicleInactiveTimerReached]`、`[Disappeared]` 这类标记——同一辆载具的「超时回收」和「已消失」原本长得一模一样，靠这列才分得开

## 隐藏噪声

引擎每次启动都会把 loot 配置、冷却组、物品库重新打印一遍，滚动文件越多重复越多，这些行没有阅读价值。工具栏的「隐藏噪声」默认勾上，把它们折叠掉：

- 有的类型（比如物资刷新）内容**全是**这类启动日志，隐藏后一条不剩——界面会直接说明原因，取消勾选可看原文
- 管理员指令里会同步剔除 `Completed in ... for 0 player profiles` 这类空转记录
- 隐藏只影响显示，原始行始终保留，随时可以关掉开关核对

## 其他能力

- **按类型分组**：登录登出、击杀、聊天、管理员指令、违规检测、经济交易、声望、载具销毁、建筑被拆… 共 19 类
- **多条件筛选**：类型标签、错误/警告级别、关键词（玩家名 / SteamID / IP / 任意词）、时间范围
- **玩家索引**：右侧列出活跃玩家及出现次数，点一下就把这个人的所有记录筛出来
- **实时跟随**：勾上「实时」，服务器正在写的日志会自动刷新
- **事件详情**：点任意一行，右侧显示完整时间、类型、级别、SteamID、IP，SteamID 可一键复制
- **导出**：把当前筛选结果存成 txt
- **快捷键**：`Ctrl+F` 搜索、`j`/`k` 逐条看、`Esc` 清空

## 日志在哪

```
SCUM/Saved/SaveFiles/Logs/
```

文件名形如 `login_20261018100021.log` —— 类型 + 滚动起始时间（年月日时分秒）。

第一次启动会自己找 Steam 装的 SCUM。找不到就点右上角「打开目录」指过去，之后会记住。

## 日志格式说明

SCUM 的日志是 **UTF-16LE 且不带 BOM** 的文本，行格式：

```
2026.10.18-11.59.09: '203.0.113.45 76561198000000001:Player01(1)' logged in at: X=100000.000 Y=20000.000 Z=30000.000
```

> 上面这行是格式示意，IP、SteamID、昵称都是虚构的。

工具会自动识别编码（UTF-16LE / UTF-16 BOM / UTF-8 都吃），并且：

- 从 `'IP SteamID64:玩家名(序号)'` 里拆出 IP、SteamID、玩家名；`Player02(ID:7656...)`、`昵称 (7656...)` 这类写法也认
- 登录文件里按 `logged in` / `logged out` 区分「登录」「登出」
- 没有时间戳的续行（击杀详情 JSON、声望明细等）会沿用上一条的时间，标成「续行」，顺序不会乱
- 每个文件开头的 `Game version` 行会被跳过（每个滚动文件都有一遍，没有信息量），跳过的条数记在 `headerLines` 里

## 大文件怎么处理

1. 单文件超过 120MB 只读尾部
2. 合并后超过 40 万行只保留最新的部分
3. 超出时界面会明确提示，不会静默丢数据

## 命令行用法

```bat
python app.py                                  :: 自动找目录，只本机可访问
python app.py --path "D:\SCUM\Saved\SaveFiles\Logs"
python app.py --path "D:\SCUM"                 :: 给上层目录也能自动定位
python app.py --port 9000 --no-browser
python app.py --host 0.0.0.0 --port 8787 --no-browser   :: 服务器模式，允许远程访问
```

也可以把日志文件夹直接拖到 `启动日志查看器.bat` 上。

网址支持直达：

```
http://127.0.0.1:8787/            :: 全部日志（默认）
http://127.0.0.1:8787/?type=login :: 直接打开某一类的合并视图（all 表示全部）
```

## 文件说明

| 文件 | 用途 |
|---|---|
| `app.py` | 后端：本地 HTTP 服务 + 日志解析引擎 |
| `web/` | 前端界面（原生 HTML/CSS/JS，无构建） |
| `启动日志查看器.bat` | 一键启动 |
| `build.py` | 打包发行版（`python build.py` → `dist/SCUMLogViewer-0.1.0.zip`） |
| `Logs/` | 你自己的日志目录（不在仓库里，也不会上传） |

`config.json` 只是记住上次打开的目录，可以随时删。

## 常见问题

**双击没反应 / 闪退**
没装 Python。到 python.org 装 3.9+，安装时勾上 "Add python.exe to PATH"。

**浏览器打开是空白**
服务默认跑在 `127.0.0.1:8787`，端口被占会自动往后找。看启动窗口里打印的实际地址。

**中文显示成乱码**
正常情况下不会——编码是自动识别的。如果遇到，欢迎开 issue 说明那个文件用了什么编码。

**能不能远程看**
默认只监听本机 `127.0.0.1`，别人访问不到。要用 `--host 0.0.0.0`（或双击 `start-server.bat`）放开，这样同网段的人都能读你的日志——只在自己能控制的网络里开。

## 部署到服务器（v0.1.0）

发行包 `SCUMLogViewer-0.1.0.zip` 解压即用，不需要 pip install：

| 文件 | 用途 |
|---|---|
| `app.py` | 后端 + 日志解析 |
| `web/` | 前端界面 |
| `start.bat` | 本机模式，自动开浏览器 |
| `start-server.bat` | 服务器模式，监听 `0.0.0.0:8787`，不开浏览器 |
| `config.json` | 记住上次日志目录，可删 |
| `VERSION` | 版本号 |

**Windows 服务器**

1. 装 Python 3.9+（勾 "Add python.exe to PATH"）
2. 把日志目录（`SCUM/Saved/SaveFiles/Logs`）拖到 `start-server.bat` 上，启动窗口会打印可访问的 IP
3. 远程机器打不开就放行端口（管理员 CMD，只需一次）：

```bat
netsh advfirewall firewall add rule name="SCUM Log Viewer" dir=in action=allow protocol=TCP localport=8787
```

4. 目录记不住也没关系：页面右上角「打开目录」指过去，会写进 `config.json`

**开机自启 / 后台常驻**

不想一直开着窗口，可以用任务计划程序建一个「登录时运行」的任务，程序填 `start-server.bat`，起始位置填解压目录。也可以用 [NSSM](https://nssm.cc/) 把 `python.exe app.py --host 0.0.0.0 --no-browser` 注册成 Windows 服务，开机就跑，不用登录。

**安全提醒**：这个工具没有任何鉴权，`0.0.0.0` 模式下能访问到端口的人都能读全部日志（含玩家 IP 和 SteamID）。只在内网或临时测试时开，别直接暴露到公网。
